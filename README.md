# The Last Violin

A ten-level chase platformer. Gather the scattered notes, defeat each tower's guardian, and play the last violin to drive back The Hush.

Play: https://vvm26br2pj-max.github.io/the-last-violin/

On iPhone, tap Share → Add to Home Screen to play full screen like an app.

## Updating

`index.html` is generated. Edit `../the-last-violin-ios.html`, then run `python3 build.py` and push. `make_icons.py` redraws the home-screen icons.
